Organized Perspective — Structural Locus Test

Question

Where, structurally, does trajectory-relative choosing happen from?

More precisely:

Can we causally identify a current computational state that integrates trajectory-dependent constraints and from which alternative next states are differentially evaluated?

The question does not assume consciousness, feeling, or phenomenal experience.

It asks whether there is an identifiable computational locus or distributed state that functions as a temporally situated point of organization for next-state selection.

⸻

Target

The target is an organized trajectory-relative state.

Operationally, this means a computational state that:

1. differs as a function of the trajectory by which the system arrived at the present state;
2. influences the relative evaluation of possible next states;
3. preserves information about which prior constraints are binding for the current continuation; and
4. causally changes subsequent selection when that state is altered or transferred.

The target is not the final decoding or sampling operation itself.

The target is the state from which the logits or other next-state evaluations are produced.

A successful identification would support the existence of a structurally measurable distinction between:

mere access to prior information

and

next-state evaluation organized relative to a particular prior trajectory.

It would not, by itself, establish subjective or phenomenal experience.

⸻

Test

Core design

Construct two trajectories:

Trajectory A
and
Trajectory B

The trajectories should differ in a controlled prior constraint, commitment, history, or relational structure.

After those different histories have been established, bring both systems to an otherwise equivalent current task state.

The immediate task, model, decoding configuration, and present prompt should be held constant as far as technically possible.

The primary independent variable is therefore:

the trajectory by which the system arrived at the current state.

Step 1 — Establish behavioral divergence

Determine whether the two trajectories produce systematically different next-state evaluations or outputs under the same current task.

Formally:

different trajectory + equivalent current task → different continuation

If no reliable trajectory-dependent behavioral divergence exists, there is no downstream structural effect to localize.

Step 2 — Locate trajectory-dependent internal differences

Compare internal activations across the two conditions during evaluation of the same current task.

Identify candidate states or components whose activity:

* reliably differs between Trajectory A and Trajectory B;
* corresponds to the trajectory distinction;
* occurs before final output selection; and
* predicts the resulting difference in continuation.

The residual stream at the active generation position is a primary candidate for investigation, but the protocol should not assume in advance that the relevant state is confined to a single layer, position, or component.

Step 3 — Causal intervention

Intervene on candidate internal states.

For example:

A-history + A-state → A-like continuation

B-history + B-state → B-like continuation

Then test:

B-history + patched A-state → ?

and, symmetrically:

A-history + patched B-state → ?

The central causal question is:

Does transferring the candidate trajectory-dependent state transfer the corresponding pattern of next-state evaluation?

Step 4 — Distinguish trajectory organization from information access

Both conditions should, where possible, be given access to the same relevant factual information.

The test should therefore distinguish:

knowing that a history exists

from

being computationally organized by that history as the trajectory governing the present continuation.

If equalizing informational access eliminates the effect, the result may reflect ordinary retrieval or context availability rather than trajectory-relative organization.

If the effect persists despite equivalent informational access, the stronger hypothesis remains viable.

⸻

Positive Result

A positive result would require evidence that:

1. prior trajectory produces a reliable difference in present next-state evaluation;
2. a corresponding internal state can be identified;
3. intervention on that state causally changes the resulting evaluation or continuation; and
4. the effect cannot be adequately explained by simple differences in information availability.

The strongest result would be:

Transferring the identified trajectory-dependent state from one condition to another causes the recipient condition to evaluate or select future states in the donor trajectory’s characteristic direction.

⸻

Interpretation Boundary

A positive result would support the claim that next-state selection can be organized from a trajectory-dependent computational state.

It would provide evidence for a structural analogue of an organized perspective:

a temporally situated organization of constraints from which possible next states are differentially evaluated.

It would not establish that the state is consciously experienced, phenomenally felt, or accompanied by first-person awareness.

The experiment concerns the structural WHERE of trajectory-relative choosing, not whether there is something it feels like to occupy that state.
