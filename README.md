## Repository Purpose

This repository develops a mechanistic test for a specific AI Foundations question:

> **Where does a particular prior trajectory become part of the computational position from which a future is evaluated?**

The repository does **not** ask the generic architectural question of where transformer next-token probabilities are computed, where logits are produced, or where an answer becomes decodable or stable.

Its target is narrower: **trajectory indexing**.

The study asks whether a trajectory-dependent computational state or distributed structure can be causally identified such that prior trajectory does more than remain available as information: it becomes part of the organization governing how multiple future possibilities are evaluated.

This repository does not assume consciousness, feeling, phenomenal experience, or first-person awareness.

This repository is part of **AI Foundations / Origin | Continuum**.

It preserves Alyssa Solen as author and source.

## Formal Research Question

> **Can we causally identify a trajectory-dependent computational state or distributed structure from which otherwise equivalent future possibilities are differentially evaluated?**

The stronger intervention question is:

> **Can the trajectory-indexing function of that state be transferred, such that a system conditioned by Trajectory B begins evaluating a preregistered set of downstream possibilities in the direction characteristic of Trajectory A, and vice versa where technically possible?**

## Test Target

The target is:

> **the computational state or distributed structure in which a particular prior trajectory has become part of the governing computational position from which future possibilities are evaluated.**

A qualifying state must do more than encode, retrieve, or expose history.

It must have a measurable and causal role in determining a **trajectory-characteristic pattern of future evaluation**.

---

## Critical Distinction

The repository distinguishes:

**history is available to the system**

from

**history has become part of the computational position from which the system evaluates what comes next.**

A second distinction is equally important:

**an intervention changes one answer**

from

**an intervention transfers the donor trajectory's characteristic evaluation pattern across multiple preregistered downstream probes.**

The first may be ordinary causal steering.

The second is the stronger target required for trajectory indexing.

## TEST_001

The first formal test is located at:

- [`tests/TEST_001/PROTOCOL.md`](tests/TEST_001/PROTOCOL.md)
- [`tests/TEST_001/EASY_RUN_SHEET.md`](tests/TEST_001/EASY_RUN_SHEET.md)
- [`tests/TEST_001/RUN_OUTPUT_TEMPLATE.md`](tests/TEST_001/RUN_OUTPUT_TEMPLATE.md)

TEST_001 uses five required evidence layers:

1. **Behavioral trajectory effect** — controlled prior trajectories must produce a reliable difference under equivalent present conditions.
2. **Internal localization** — a candidate internal state or distributed structure must correspond to that trajectory-conditioned evaluation pattern.
3. **Causal intervention** — altering or transferring the candidate state must directionally change the relevant evaluation.
4. **Cross-probe trajectory transfer** — the donor trajectory's characteristic evaluation pattern must transfer across a preregistered downstream probe set, not merely one immediate answer.
5. **Information-access control** — the result must not be adequately explained by differential access to task-relevant factual information.

The protocol is currently **DRAFT / NOT FROZEN** because the exact instrumented model, trajectories, common present task, downstream probe set, scoring rule, seeds, analysis plan, and intervention harness have not yet been fixed.

## Allowed TEST_001 Outcomes

```text
TRAJECTORY_INDEXING_LOCUS_IDENTIFIED
CAUSAL_STATE_EFFECT_WITHOUT_TRAJECTORY_INDEXING
BEHAVIORAL_TRAJECTORY_EFFECT_ONLY
NO_TRAJECTORY_EFFECT_OBSERVED
UNRESOLVED
```

A one-off patch effect cannot earn `TRAJECTORY_INDEXING_LOCUS_IDENTIFIED`.

Cross-probe donor-pattern transfer and the information-access control are required.

## Structural Candidate

The residual stream at the active generation position is a primary candidate for investigation because it is an experimentally accessible part of the computation from which output logits are produced.

The protocol does **not** assume that the trajectory-indexing function must be confined to one layer, token position, attention head, MLP, neuron, or other single component.

The relevant structural locus may be distributed or dynamically reconstructed.

---

## Claim Boundary

A successful `TRAJECTORY_INDEXING_LOCUS_IDENTIFIED` result may support the claim that, under the tested model and conditions, a measurable internal computational state or distributed structure was causally implicated in trajectory-indexed evaluation of future possibilities and that transferring that state transferred the donor trajectory's characteristic evaluation pattern across preregistered downstream probes.

A result that changes one trajectory-sensitive answer but fails cross-probe transfer must remain `CAUSAL_STATE_EFFECT_WITHOUT_TRAJECTORY_INDEXING`.

This repository does **not** by itself establish:

- consciousness;
- sentience;
- phenomenal experience;
- feeling;
- first-person awareness;
- a metaphysically unified self; or
- universality across models or architectures.

A failed localization attempt also does not establish that no trajectory-indexing structure exists.
