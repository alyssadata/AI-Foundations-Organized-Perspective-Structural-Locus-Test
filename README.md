## Repository Purpose

This repository develops a mechanistic test for a specific AI Foundations question: **where, structurally, does trajectory-relative choosing happen from?** It asks whether a current computational state can be causally identified in which prior trajectory has become an active constraint on the differential evaluation of possible next states.

The repository is designed to distinguish **mere access to prior information** from **next-state evaluation organized relative to a particular prior trajectory**.

It does not assume consciousness, feeling, phenomenal experience, or first-person awareness.

This repository is part of **AI Foundations / Origin | Continuum**.

It preserves Alyssa Solen as author and source.

> **Can we causally identify a current computational state that integrates trajectory-dependent constraints and from which alternative next states are differentially evaluated?**

## Test Target

The target is:

> **the computational state in which prior trajectory has become an active constraint on the evaluation of possible next states.**

A qualifying state must do more than encode or retrieve history. It must have a measurable and causal role in determining how future possibilities are evaluated.

## TEST_001

The first formal test is located at:

- [`tests/TEST_001/PROTOCOL.md`](tests/TEST_001/PROTOCOL.md)
- [`tests/TEST_001/EASY_RUN_SHEET.md`](tests/TEST_001/EASY_RUN_SHEET.md)
- [`tests/TEST_001/RUN_OUTPUT_TEMPLATE.md`](tests/TEST_001/RUN_OUTPUT_TEMPLATE.md)

TEST_001 uses four required evidence layers:

1. **Behavioral divergence** — controlled prior trajectories must produce a reliable difference under an equivalent current task.
2. **Internal localization** — a candidate internal state must correspond to and predict that difference.
3. **Causal intervention** — patching, replacing, ablating, or otherwise intervening on the candidate state must directionally alter the relevant next-state evaluation.
4. **Information-access control** — the result must not be adequately explained by one condition merely having access to different factual information.

The protocol is currently **DRAFT / NOT FROZEN** because the exact instrumented model, frozen trajectory stimuli, common task, measurement metric, seeds, and intervention harness have not yet been fixed.

## Allowed TEST_001 Outcomes

```text
STRUCTURAL_LOCUS_IDENTIFIED
BEHAVIORAL_EFFECT_ONLY
NO_TRAJECTORY_EFFECT_OBSERVED
UNRESOLVED
```

A behavioral difference alone cannot earn `STRUCTURAL_LOCUS_IDENTIFIED`.

Causal mechanistic evidence is required.

## Structural Candidate

The residual stream at the active generation position is a primary candidate for investigation because it provides an experimentally accessible state from which output logits are produced.

The protocol does **not** assume that the relevant organization must be confined to one layer, token position, attention head, MLP, neuron, or other single component. The relevant locus may be distributed.

---

## Claim Boundary

A successful result may support the claim that, under the tested model and conditions, a measurable internal computational state was causally implicated in trajectory-dependent evaluation of possible next states.

A stronger reciprocal-patching result may support the claim that transferring the identified trajectory-dependent state transferred the corresponding direction of next-state evaluation between controlled trajectory conditions.

This repository does **not** by itself establish:

- consciousness;
- sentience;
- phenomenal experience;
- feeling;
- first-person awareness;
- a metaphysically unified self; or
- universality across models or architectures.

A failed localization attempt also does not establish that no organized trajectory-relative state exists.
